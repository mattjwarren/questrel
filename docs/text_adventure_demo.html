Text Adventure Demo

Questrel includes a very small interactive "old-school" text adventure demo. It seeds a demo database, generates a play, maps the generated locations into a handful of rooms, places characters and props, and then lets you navigate using a classic command vocabulary.

How to run

The easiest way to run it without installing the package is via the repository runner script: 


uv run text_adventure_demo.py

It writes logs to questrel_text_adventure.log by default. You can disable logging by editing the defaults in the demo or calling run_repl(no_log=True).

What it does

  1. Optionally seeds the demo DB (same dataset used by the CLI demo).
  2. Calls questrel.api.generate_play_from_url to generate a play (nodes, edges, bindings).
  3. Builds a tiny world map from the generated location bindings (up to 4 rooms).
  4. Places generated characters and props into rooms (round-robin placement).
  5. Starts a REPL loop that parses commands and updates state.

Command vocabulary

  • Movement: n, s, e, w, ne, nw, se, sw, u, d (or go <dir>)
  • Look: look (or l)
  • Inventory: inv (or i)
  • Story: story (reprints current story node)
  • Advance: next (applies Questrel branching to move to the next story node)
  • Actions: get <item>, drop <item>, use <item> [on <target>], talk <person>, attack <person>, give <item> to <person>
  • Debug: flags (shows state flags)
  • Help: help
  • Exit: quit

How branching works in the demo

The demo uses Questrel's resolver to choose the next edge from the current story node:

  • Outgoing edges are filtered by condition expressions against state.flags.
  • Highest priority edges win; within the tier, the demo uses weighted selection.
  • The RNG is deterministic using the generated play seed + current node + step index.

How player actions affect the story

This demo is intentionally simple; it does not implement a full rule system. Instead, a few actions set state flags that are referenced by the seeded conditions:

  • get key or using a key sets has_key=True
  • get scroll or using a scroll sets magic=True
  • get sword or attacking certain characters sets brave=True
  • Talking to certain characters may set allow=True

You can inspect current flags at any time with flags, then use next to advance and observe how different flags unlock different edges.
