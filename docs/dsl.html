Condition DSL

Questrel uses an author-friendly string expression DSL evaluated safely via AST validation and interpretation.

Access style

state.flags["x"]

Missing keys evaluate as None.

Examples


state.flags["met_mayor"] == True and state.flags["reputation"] >= 10
state.flags["key"] != None
state.flags["faction"] in ["mages", "thieves"]

Limits

  • Max length: 8192 chars
  • Max AST nodes: 1024
  • Max AST depth: 48
